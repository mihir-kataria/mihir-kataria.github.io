# Terminology sample

This page shows the one term chosen for each AIAG concept, so every page uses the same words. It's for anyone writing or editing the AIAG docs.

| Use | Don't use | Meaning and notes |
| --- | --- | --- |
| AIAG | ASU GPT, ASUGPT, GPT Bot | The product. Define once per page as "AIAG (ASU Instructor Assistant GPT)" where needed. "The bot" is acceptable in the student guide. |
| admin panel | admin control panel, instructor control panel | The instructor pages for connecting a course and choosing materials. |
| chat | thread, conversation, chat session | One saved sequence of questions and answers in the sidebar. |
| teaching staff | course staff, instructional team, moderators | Instructors and TAs together. Use "instructor" when only instructors can do something. In the student guide, say "your instructor or TA". |
| knowledge base | vector database (as a concept), dataset | All the content AIAG can retrieve for one course. |
| passage | match, engine result | One retrieved item: a discussion post, a reply, or a document chunk. |
| sources | citations, references | The passages shown to students in the **Source** tab. |
| relevance check | relevance filter, classifier | The LLM call that decides whether a question is about the course. |
| escalation | HITL post, ask a human | Posting an unanswered question to the course discussion board. In technical docs, define "human-in-the-loop (HITL)" once. In the student guide, say "post your question to the discussion board". |
| discussion board | discussion forum | Canvas Discussions or Ed Discussion. |
| Chinese, Mandarin | Simplified Chinese, zh (in prose) | Use "Chinese" for the language setting and written text. Use "Mandarin" only for spoken voice input. |
